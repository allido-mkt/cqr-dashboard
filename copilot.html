2 ค้นหารายการ

ใช้ Game + Month เพื่อดูภาพรวม หรือใส่ Hash/Run ID เพื่อเจาะรายการเดียว

3 Preview ก่อนเสมอ

ให้ n8n ตรวจจำนวนแถวและช่วงข้อมูลก่อนทำการลบจริง

4 Clear แล้ว Build

หลัง Preview ถูกต้อง ค่อย Clear ข้อมูลเก่า แล้ว Build Master ใหม่เฉพาะรอบนั้น

วิธีค้นหาที่แนะนำ
ใช้หน้านี้เฉพาะเวลาต้องซ่อมข้อมูลเอง เช่น Data Health เจอ hash mismatch หรือ Build รอบนั้นยังไม่สมบูรณ์. ถ้าไม่ใส่ Hash/Run ID ระบบจะแสดง run ที่เกี่ยวข้องของ Game + Month ที่เลือก. ถ้าใส่ Run ID รายเกม ระบบจะยึดเกมจาก Run ID นั้นเพื่อป้องกันการ Clear ผิดเกม.
หมายเหตุ: Auto Pipeline วันอาทิตย์ยังทำงานตามเวลาเดิม หน้านี้ไม่ไปปิด Auto แต่ไม่ควรกด Manual Clear/Build ทับช่วง Auto กำลังรัน.
RAW FILE CHECK

ตรวจไฟล์ Raw ของ Game/Month ที่เลือกอีกครั้ง แล้วบันทึกผลลง Central DB ถ้าไฟล์เหมือนเดิมจะบอกว่าปกติ ถ้ามีข้อมูลใหม่จะบอกว่าอัปเดทใหม่ ถ้าขาด Tab จะบอกว่าข้อมูลไม่ครบ

ยังไม่ได้ตรวจ Raw File จากหน้านี้

ใช้ปุ่มนี้เมื่อต้องการตรวจ Raw เฉพาะรอบที่เลือกเอง เช่น CBM TH เดือนเมษายน ก่อนซ่อมข้อมูลใน Data Control

MANUAL ACTIONSเลือกรายการที่ต้องจัดการก่อน
ยังไม่ได้ส่งคำสั่งซ่อม หลังจากเลือก run แล้ว ให้เริ่มจาก Preview ก่อนเสมอ ผลของ Preview / Clear / Build จะแสดงตรงนี้
เลือกเกม/เดือน แล้วกด FIND เพื่อดู run ที่เกี่ยวข้องและคำแนะนำขั้นตอนถัดไป
