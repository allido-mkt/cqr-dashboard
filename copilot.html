1 เช็กข้อมูลก่อน

ไปที่ Data Health Checkup เพื่อดูว่าเกม/เดือนนี้มีไฟล์ค้างหรือ hash ชนกันไหม

2 หา Run ID

ใช้ปุ่ม Find Run ID เพื่อหาว่า run ไหนเป็นข้อมูลเก่าที่ต้องตรวจต่อ

3 Preview Cleanup

ให้ n8n สรุปก่อนว่าจะลบกี่แถว ยังไม่ลบข้อมูลจริงในขั้นตอนนี้

4 Cleanup แล้ว Update

ถ้าจำนวนแถวถูกต้อง ค่อย Run Cleanup แล้วตามด้วย Run Update

Run ID / Hash ใช้ต่างกันยังไง
ใส่ Run ID เมื่อต้องการตรวจ run ที่รู้แน่ชัดแล้ว · ใส่ Hash เมื่อต้องการหา run ที่ทำให้เกิดปัญหา hash mismatch · ถ้าไม่ใส่อะไร ระบบจะค้น run ที่เกี่ยวข้องกับเกมและเดือนที่เลือกให้กว้างขึ้น
ไม่จำเป็นต้องใส่เสมอไป แต่ถ้าเจอ hash จากหน้า Health ให้ใส่ตรงนี้เพื่อหา run_id
Step 3 Preview Cleanup

ส่งคำสั่งไปที่ n8n เพื่อเช็กก่อนว่าจะลบแถวไหนบ้าง ยังไม่ลบข้อมูลจริง ใช้ปุ่มนี้ก่อนทุกครั้ง

Step 4A Run Cleanup

ส่งคำสั่งลบข้อมูลเก่าผ่าน n8n ใช้เฉพาะหลัง Preview แล้วจำนวนแถวถูกต้องเท่านั้น

Step 4B Run Master Data Update

ส่งคำสั่งให้ n8n อ่าน raw file แล้วเขียน Master / Central DB ใหม่สำหรับเกมและเดือนที่เลือก

ยังไม่มีคำสั่งล่าสุด เริ่มจาก Data Health Checkup ก่อน ถ้าเจอปัญหา hash mismatch ค่อยกลับมาที่ Data Control เพื่อ Find Run ID, Preview Cleanup, Run Cleanup และ Run Update ตามลำดับ
เลือกเกม/เดือน แล้วกด Find Run ID เพื่อดู run ที่เกี่ยวข้องและคำแนะนำขั้นตอนถัดไป
